# 工具定义

## shop_getById

描述: 根据ID查询商铺详情，包含营业时间、评分、地址、人均消费等信息

参数:
| 参数名 | 类型 | 必填 | 描述 |
|--------|------|------|------|
| id | long | 是 | 商铺ID |

返回: 商铺详情信息（名称、评分、人均、营业时间、地址、商圈、销量、评论数）

## shop_searchByName

描述: 根据商铺名称关键字搜索商铺列表

参数:
| 参数名 | 类型 | 必填 | 描述 |
|--------|------|------|------|
| name | string | 是 | 商铺名称关键字 |

返回: 匹配的商铺列表（名称、评分、人均、地址）

## shop_getByType

描述: 根据商铺类型ID查询商铺列表，支持按距离排序

参数:
| 参数名 | 类型 | 必填 | 描述 |
|--------|------|------|------|
| typeId | long | 是 | 商铺类型ID |
| x | double | 否 | 用户坐标经度 |
| y | double | 否 | 用户坐标纬度 |

返回: 该类型的商铺列表

## shop_getTypes

描述: 获取所有商铺分类列表

参数:
| 参数名 | 类型 | 必填 | 描述 |
|--------|------|------|------|
| 无 | - | - | 无参数 |

返回: 商铺分类列表（名称、ID）

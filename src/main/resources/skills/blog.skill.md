# 工作流程

此技能采用 **Agent触发 + 前端写作板执行 + 多Agent并行创作** 的架构：

```

└────────────────────────────────────────────────────────────────────┘
                              ↓
┌────────────────────────────────────────────────────────────────────┐

│  1. 用户上传探店照片                                                   │
│  2. 用户选择关联店铺                                                   │
```

# Agent 职责

| Agent | 职责 | 输入 | 输出 |
|-------|------|------|------|
| ImageAnalyzer | 多模态图片分析 | 图片URL | 菜品类型、环境、氛围、亮点 |
| TitleAgent | 生成吸引人的标题 | 图片分析+店铺信息 | 标题文本（≤30字） |
| ContentAgent | 生成爆文正文 | 图片分析+店铺信息 | 正文内容（层次分明） |
| BlogPublisher | 保存发布笔记 | 草稿数据 | 博客ID |

**并行优势**：TitleAgent 和 ContentAgent 同时执行，创作速度提升约50%

# 工具定义

## blog/startDraft

描述: 启动笔记写作流程，创建草稿并返回触发指令让前端显示写作板

参数:
| 参数名 | 类型 | 必填 | 描述 |
|--------|------|------|------|
| wordCount | integer | 否 | 目标字数（50-500），默认150 |

返回: 触发指令 `[BLOG_WRITING_PANEL:draftId={draftId}]`

**重要：Agent只负责触发写作板，后续流程由写作板组件处理**

# 爆文内容模板

生成的笔记必须遵循以下结构，层次分明、吸引眼球：

## 标题模板（选一种）

1. **情绪共鸣型**：`终于找到这家XXX了！/ X刷的宝藏店铺，必须安利！`
2. **好奇心型**：`人均XX的XXX，真的值得吗？/ 这家XXX凭什么这么火？`
3. **价值型**：`XX元吃饱！XXX人均攻略 / 这家XXX，性价比天花板！`
4. **场景型**：`约会必去！这家XXX太浪漫了 / 聚餐首选！XXX超适合朋友聚会`

## 正文结构（必须遵循）

```
【开场引入】（1-2句）
- 用一句话引起共鸣或好奇心
- 例如："听说这家店很久了，终于来打卡！"

【环境/氛围】（2-3句）
- 描述店铺环境特色
- 例如："进门就是浓郁的港风装修，灯光很温馨～"

【核心推荐】（分段展示，每道菜1-2句）
- 推荐具体菜品，每道菜单独一段
- 描述口感、味道
- 例如："🥢 招牌蛋挞：外酥里嫩，咬下去满口奶香！"

【实用信息】（总结段）
- 人均价格、适合场景
- 例如："💰 人均XX元，适合朋友聚餐/约会打卡"

【结尾互动】（1句）
- 引导互动
- 例如："你们觉得值得去吗？评论区聊聊～"
```

## 格式要求

- **换行分隔**：每个段落之间必须换行
- **emoji点缀**：每段开头或关键处添加emoji增加视觉吸引力
- **短句为主**：避免长句，每句不超过20字
- **层次分明**：开场、环境、推荐、信息、结尾五个部分清晰

## 示例爆文

**标题**：二刷这家港式茶餐厅，真的太好吃了！

**正文**：
听说这家港式茶餐厅很久了，这次终于来打卡！

店里装修很有港风味道，复古的霓虹灯牌、木质卡座，氛围感满满～

🥢 冰火菠萝油
外皮酥脆到掉渣，里面的黄油冰凉香甜，一口下去绝了！

🥢 招牌蛋挞
蛋挞皮酥松，蛋液嫩滑香甜，趁热吃最好！

🥢 XO酱炒牛河
牛河爽滑不油腻，XO酱香气浓郁，分量很足！

💰 人均45元，适合朋友聚餐或下午茶时光

你们去过这家吗？觉得怎么样？评论区聊聊～
